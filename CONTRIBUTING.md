# Contributing to Helix

Issues and pull requests are welcome.

## License and CLA

Helix is licensed under the [GNU AGPL-3.0](LICENSE). Before your first pull request can be merged, you need to
sign the [Contributor License Agreement](CLA.md). The CLA Assistant bot asks you to sign in your first pull request,
and it takes one click. You keep the copyright to your work. The CLA lets the maintainer keep offering Helix
under other license terms too (for example a commercial license), and the public version stays AGPL-3.0.

## Pull requests

- Keep changes small and focused, and write one topic per pull request.
- Run `npm run typecheck` and `npm test` in `pc-gateway/` before you open one.
- Never commit secrets: `.env`, `.p8`/`.pem`/`.key` files, tokens, databases or `data/`.

## Name

The name "Helix" and the Helix logo are not covered by the AGPL-3.0 license. Forks are welcome, but please give
them a different name.
